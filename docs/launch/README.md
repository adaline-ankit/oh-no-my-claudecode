## Claims policy

- Tie a metric to its protocol, baseline, sample size, and environment.
- Separate synthetic/component checks from live coding outcomes.
- Report ties and failures. Do not turn a small pilot into an accuracy claim.
- Default receipts are tamper-evident; optional attestation is a separate workflow.
- A verifier only establishes the properties its evidence covers.
- Cost is unknown when the agent/provider does not report it.
- Working context is advisory. Source identity is not semantic truth.
